# DLC Catalog

Серверная часть системы каталога и выдачи дополнений (DLC) к игре.

Веб-приложение
позволяет просматривать каталог игровых дополнений, выполнять
поиск и фильтрацию, регистрироваться и получать дополнения
в личную библиотеку.

## Используемые технологии

- PHP 8.4
- Laravel 12
- PostgreSQL 16
- Nginx
- HTML5, CSS3, JavaScript
- Blade
- Docker и Docker Compose
- Composer
- Git

Архитектура приложения основана на паттерне MVC
с использованием сервисного слоя.

## Системные требования

Для запуска приложения необходимо установить:

- Git;
- Docker Engine или Docker Desktop;
- Docker Compose V2.

Отдельная установка PHP, PostgreSQL, Nginx и Composer
не требуется, поскольку они используются внутри
Docker-контейнеров.

## Установка и запуск

### 1. Клонирование репозитория

git clone https://github.com/pick-rxdixn/dlc-catalog.git
cd dlc-catalog

### 2. Создание файла конфигурации

cp .env.example .env

В файле `.env` необходимо установить следующие параметры:

APP_NAME="DLC Catalog"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://localhost:8080

DB_CONNECTION=pgsql
DB_HOST=db
DB_PORT=5432
DB_DATABASE=dlc_catalog
DB_USERNAME=dlc_user
DB_PASSWORD=dev_password_2026

SESSION_DRIVER=database

Указанные параметры предназначены для локального запуска
приложения.

### 3. Сборка и запуск Docker-контейнеров

docker compose up -d --build

Проверка состояния контейнеров:

docker compose ps

### 4. Установка зависимостей Laravel

docker compose exec app composer install

### 5. Генерация ключа приложения

docker compose exec app php artisan key:generate

### 6. Настройка прав доступа

Для корректной работы Laravel необходимо предоставить
права записи в служебные директории:

bash scripts/fix-permissions.sh

### 7. Создание структуры базы данных

docker compose exec -u www-data app php artisan migrate

### 8. Заполнение базы данных

docker compose exec -u www-data app php artisan db:seed

В результате в базе данных будут созданы записи
о трёх играх, трёх категориях и девяти дополнениях.

### 9. Открытие приложения

После выполнения предыдущих шагов приложение доступно
в браузере по адресу:

http://localhost:8080

Для получения дополнений необходимо зарегистрировать
пользовательский аккаунт.

## Основные возможности

- Регистрация и авторизация пользователей.
- Просмотр каталога игровых дополнений.
- Поиск дополнений по названию.
- Фильтрация по игре и категории.
- Просмотр подробной информации о дополнении.
- Получение дополнений в личную библиотеку.
- Защита от повторного получения дополнения.
- Просмотр личной библиотеки и даты получения DLC.
- Отображение статуса полученных дополнений в каталоге.

## Остановка приложения

docker compose stop

## Повторный запуск

docker compose up -d

При повторном запуске установка зависимостей,
выполнение миграций и заполнение базы данных
не требуются, если данные и файлы проекта сохранены
и структура базы данных не изменялась.

## Удаление контейнеров

docker compose down

Данные PostgreSQL сохраняются в постоянном Docker-томе.

Внимание: команда `docker compose down -v` удаляет
контейнеры и тома вместе со всеми данными базы данных.
